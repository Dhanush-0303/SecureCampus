# 🛡️ SecureCampus - Enterprise Student Management Portal

SecureCampus is a Flask-based web application backed by PostgreSQL, designed to securely manage student enrollment, academic performance records, and administrative access control.

## 🚀 Features
- **Student Directory**: Dashboard interface for tracking campus enrollments and department statuses.
- **Enterprise Database Backend**: Built on PostgreSQL with SQLAlchemy connection pooling (`pool_pre_ping`).
- **Session & Token Security**: Combines session authentication via `Flask-Login` with JWT security via `Flask-JWT-Extended`.
- **Database Architecture**: Clean handling of foreign key dependencies and schema constraints.

## 🛠️ Tech Stack
- **Backend**: Python, Flask, Flask-SQLAlchemy, Flask-Login, Flask-JWT-Extended, Bcrypt
- **Database**: PostgreSQL, psycopg2
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap
